# 원천세 실무 실습

가상회사 (주)끌림상사의 1년 원천세 신고 사이클을 처음부터 끝까지 따라가는 실습용 웹 프로그램입니다.

## 실습 구성 (15개 모듈)

1. 오리엔테이션 — 원천세 신고 캘린더
2. 급여대장 작성
3. 비과세 근로소득 판단
4. 4대보험 검토
5. 간이세액표 적용
6. 원천징수이행상황신고서 작성 (매월분)
7. 일용근로소득 계산
8. 일용근로소득지급명세서 & 동시신고
9. 중도퇴사자 처리 (근로소득 정산 + 퇴직소득)
10. 근로소득 간이지급명세서
11. 소득구분 판단 (사업소득 vs 기타소득)
12. 근로+사업+기타 동시신고
13. 사업소득·기타소득 간이지급명세서
14. 근로+이자+배당 동시신고
15. 연말정산 & 근로소득원천징수영수증

## 특징

- 실제 서식(원천징수이행상황신고서 별지 제21호 등)의 항목 번호를 그대로 사용
- 모듈을 통과해야 다음 단계가 열리는 단계 잠금 방식
- 입력 내용은 브라우저(localStorage)에 자동 저장
- 별도 서버 없이 `index.html` 하나로 동작
